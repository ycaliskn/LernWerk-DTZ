# LernWerk project instructions

- Keep the product aligned to German A1–B1 and DTZ everyday communication.
- Preserve staged releases: complete and review A1 first, then A2, then B1.
- Every grammar unit must cite a source record in `app/sources.js`; keep source IDs, direct URLs, checked dates and rights notes accurate.
- Prefer original explanations, examples, questions and artwork. Do not bulk-copy copyrighted Goethe, telc, BAMF, DVV, DW or teacher/course content.
- Do not label the project as endorsed by Goethe-Institut, telc, BAMF, DVV or DW.
- Maintain offline-first guest progress. Account linking must preserve data and require explicit user consent before upload.
- Never store secrets, API keys, signing certificates or store credentials in the repository.
- Before presenting a release candidate, run the web tests three times, Java tests three times, syntax checks, source/licence review, and Android/iOS build workflows. State exactly which checks did and did not run.
- Keep `main` protected and use pull requests / required CI checks.
