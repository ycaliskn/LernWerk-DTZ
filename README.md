# LernWerk – Deutsch A1–B1 / DTZ

This repository contains the LernWerk mobile-responsive, offline-first German learning prototype. See `docs/ARCHITECTURE.md`, `docs/TEST_REPORT.md` and `docs/BUILD_AND_RELEASE.md`.

## Current status

A1 is a small demonstration dataset, not a complete Goethe A1 catalogue. Android/iOS build workflows are configured but have not yet been executed. Physical device testing, production authentication/sync, live AdMob and store billing are not complete.

## Quick start

```bash
npm start
npm test
npm run test:3x
npm run api:test
```
